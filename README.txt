موقع عيد ميلاد بوشريشتي — نسخة مجهّزة لإشعار Telegram عبر Netlify Functions

قبل النشر:
1) تأكد أن البوت تاعك مفتوح في Telegram وأنك ضغطت Start فيه، وإلا ما يقدرش يبعثلك رسالة.
2) في Netlify افتح Site configuration / Environment variables (أو Project configuration حسب الواجهة) وأضف:
   TELEGRAM_BOT_TOKEN = التوكن السري الذي أعطاك إياه @BotFather
   TELEGRAM_CHAT_ID = 1520061492
   لا تضع التوكن داخل index.html ولا ترسله لأي شخص.
3) لازم تنشر المشروع بطريقة تدعم Netlify Functions. الأسهل عادةً ربط مستودع GitHub بالموقع ورفع محتويات هذا المجلد للمستودع؛ netlify.toml و netlify/functions/notify-yes.mjs يجب أن يكونا في جذر المشروع. السحب والإفلات اليدوي لملفات الموقع وحدها قد لا ينشر الـ Function.
4) بعد إضافة متغيرات البيئة، أعد نشر الموقع (Trigger deploy / Deploy site).
5) افتح رابط الموقع بنفسك، واضغط «نعم» للاختبار. إذا كان كل شيء مضبوطًا، تصلك رسالة في Telegram.

الملفات:
- index.html: الموقع
- netlify/functions/notify-yes.mjs: وظيفة الخادم التي تبعث الإشعار دون كشف التوكن للزوار
- netlify.toml: إعداد مجلد الوظائف

ملاحظات أمان:
- لا تشارك Telegram Bot Token في الدردشة أو في كود الواجهة الأمامية.
- الوظيفة تتحقق من نوع الطلب وقيمة الإجابة، لكن رابطًا عامًا قد يتعرض لطلبات متكررة؛ إذا صار هذا مشكلة، أضف حماية إضافية/مكافحة إساءة الاستخدام قبل استخدامه على نطاق واسع.
